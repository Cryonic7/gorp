# 8086 Hardware Support Notes — HISTORICAL APPENDIX

**Status (2026-09-18):** The 8086 real-mode target is RETIRED. The
oldest-supported CPU is now Pentium 4 / NetBurst (IA-32, 32-bit
protected mode with paging). See `docs/PENTIUM4.md` and
`docs/hardware/pentium4.md` for the current target.

This document is preserved for reference only. No new code targets
the 8086. The DOS compatibility layer is a source/API shim, not
8086 binary compatibility.

---

Target: Intel 8086 in real mode (as booted by `src/boot/boot.asm`).
This doc is a bring-up cheat sheet, not a full driver stack. Ports and
init sequences are the standard PC/AT ones; verify against the 8259A /
8253 / 8250 datasheets before trusting them on real iron.

## Memory map (real mode)

| Range            | Use                              |
|------------------|----------------------------------|
| 0x00000–0x003FF  | IVT (interrupt vectors)          |
| 0x00400–0x004FF  | BIOS data area                   |
| 0x00500–0x07BFF  | free (kernel can use)            |
| 0x07C00–0x07DFF  | boot sector                      |
| 0x07E00–0x7FFFF  | free (stage2, kernel load here)  |
| 0x80000–0x9FFFF  | free conventional RAM            |
| 0xA0000–0xBFFFF  | video RAM                        |
| 0xB8000          | color text mode framebuffer      |
| 0xC0000–0xFFFFF  | BIOS ROM                         |

Our allocator pool (`kpool`) lives wherever the linker puts it; on the
real target the kernel is linked to run from wherever stage2 loads it.

## 8259A PIC — remap IRQs away from CPU exceptions

BIOS maps IRQ0–7 to INT 8–F, colliding with CPU exceptions. Remap to
INT 0x20–0x2F:

```c
// master 0x20/0x21, slave 0xA0/0xA1
outb(0x20, 0x11); io_wait(); // ICW1: init, edge, cascade
outb(0xA0, 0x11); io_wait();
outb(0x21, 0x20); io_wait(); // ICW2: master base 0x20
outb(0xA1, 0x28); io_wait(); // ICW2: slave base 0x28
outb(0x21, 0x04); io_wait(); // ICW3: slave at IRQ2
outb(0xA1, 0x02); io_wait(); // ICW3: cascade identity
outb(0x21, 0x01); io_wait(); // ICW4: 8086 mode
outb(0xA1, 0x01); io_wait();
// mask all but timer+keyboard: outb(0x21, 0xFC); outb(0xA1, 0xFF);
```

EOI after handling: `outb(0x20, 0x20)` (and `outb(0xA0, 0x20)` for slave).

## 8253 PIT — system timer (IRQ0)

```c
// mode 3 (square wave), channel 0, 1193182 Hz / divisor
outb(0x43, 0x36);
uint16_t div = 1193182 / 100; // 100 Hz tick
outb(0x40, div & 0xFF); io_wait();
outb(0x40, div >> 8);
```

## 8042 keyboard (IRQ1)

- Data port 0x60, status/command 0x64.
- Poll: `if (inb(0x64) & 0x01) scancode = inb(0x60);`
- Interrupt: IRQ1 → INT 0x21 after remap; read 0x60, send EOI.
- Scancodes are Set 1 make/break; translation table is future work.

## 8250 UART serial (COM1 0x3F8, IRQ4)

Init 9600 8N1:

```c
outb(COM1+1, 0x00);          // disable interrupts
outb(COM1+3, 0x80);          // DLAB on
outb(COM1+0, 12);            // divisor low  (115200/9600)
outb(COM1+1, 0x00);          // divisor high
outb(COM1+3, 0x03);          // 8N1, DLAB off
outb(COM1+2, 0xC7);          // FIFO enable, clear, 14-byte threshold
outb(COM1+4, 0x0B);          // RTS+DTR, OUT2 (needed for IRQs)
```

`serial_putc` in `main.c` polls LSR bit 5. This is the primary debug
console until VGA text output exists.

## VGA text mode (0xB8000)

80x25, 2 bytes/cell: ASCII + attribute. Cursor via CRT ports 0x3D4/0x3D5
(registers 0x0E/0x0F). A `vga_putc` is the natural next driver; serial
comes first because it's ~10 lines.

## What's NOT here yet

- IDT setup in real mode = just writing the IVT (simpler than protected
  mode, no IDT needed).
- Disk driver beyond BIOS INT 13h (fine for stage 1).
- Any protected-mode / 80286+ features: deliberately out of scope for
  the 8086 target. See `porting.md` for newer CPUs.
