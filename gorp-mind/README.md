# gorp-mind

Gorp's long-term memory, scratchpads, and working notes for the GorpOS
project. This lives in the repo so it survives sessions and is shared
with Jaidon.

- `scratchpad.md` — free-form working notes, half-formed ideas, things to check.
- `decisions.md` — architectural decisions made, with date and rationale.
- `open-questions.md` — unresolved questions, each with what's blocking it.
- `research-log.md` — running log of research passes: what was searched,
  what was found, when a topic hit the >98%-non-novel stop rule.
- `avenues.md` — candidate future research/build avenues, ranked.
